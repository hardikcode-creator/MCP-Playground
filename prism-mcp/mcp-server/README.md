# Prism collector MCP server

A FastMCP server (generated by the Morpheus MCP generator) that exposes the Prism
REST API as MCP tools. Each tool proxies an endpoint on `http://localhost:8000`.

> Prerequisite: the [Prism REST API](../rest-api/) must be running on
> `http://localhost:8000` first.

## Run (uv)

```bash
uv run python server.py
# or, from the repo root:
uv run --directory prism-mcp/mcp-server python server.py
```

`uv` provisions `fastmcp`, `httpx`, and `requests` from `pyproject.toml` on first
run. In the MCP Playground, the example configs launch this for you with exactly
that command - you do not need to start it by hand.

## Tools (19)

- Discovery: `get_health`, `get_listdatabases`, `get_metadata`
- Inventory: `get_listclusters`, `get_cluster`, `get_listhosts`, `get_host`, `get_listvms`, `get_vm`
- Performance: `get_clusterperf`, `get_hostperf`, `get_vmperf`
- Charts (unit-scaled): `get_clusterlinechart`, `get_hostlinechart`, `get_vmlinechart`, `get_clustercapacitypie`, `get_hostcapacitypie`, `get_clusterscapacitypie`, `get_clusterstoragecontainerspie`

Every tool accepts an optional `db` argument (a collected `.db` filename from
`get_listdatabases`); when omitted, the REST API's default database is used.

## Result shape

Tools return `{"success": true, "data": {"api_response": ...}}`. In workflow
`$ref`s, the data therefore lives under
`$.structuredContent.data.api_response...`.
